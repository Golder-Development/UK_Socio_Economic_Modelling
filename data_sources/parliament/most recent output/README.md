# Most Recent Output

This folder contains shared outputs generated from the cabinet ministers dataset that can be referenced by multiple analysis scripts without requiring data to be re-fetched.

## Contents

### `cabinet_ministers.csv` (from most recent extract)

**Location**: `../most recent extract/cabinet_ministers.csv`

Source cabinet ministers dataset (3,745+ records) with enriched fields:

- **Basic Info**: given_name, family_name, person_id, mnis_id
- **Post Details**: post, member_house (Commons/Lords)
- **Tenure**: start_date, end_date, tenure_length_days
- **Parliament**: parliament_start_date, parliament_length_days
- **Affiliation**: party, prime_minister

### `parliaments_periods.json`

**Generated by**: `build_sos_churn_by_parliament.py`
**Format**: JSON array of parliament records
**Cache Type**: Local cache to avoid repeated API calls

Contains parliament session metadata:

```json
[
  {
    "parliament_number": 55,
    "parliament_start_date": "2010-05-18",
    "parliament_end_date": "2015-03-30",
    "parliament_duration_days": 1778
  },
  ...
]
```

**Usage**: Other scripts can load this file to avoid calling the parliament periods API:

```python
import json
import pandas as pd
from pathlib import Path

parls_cache = Path("data_sources/parliament/most recent output/parliaments_periods.json")
with open(parls_cache, "r") as f:
    parls_data = json.load(f)
parls = pd.DataFrame(parls_data)
parls["parliament_start_date"] = pd.to_datetime(parls["parliament_start_date"])
parls["parliament_end_date"] = pd.to_datetime(parls["parliament_end_date"])
```

### `parliamentary_churn_summary.csv`

**Generated by**: `build_sos_churn_by_parliament.py`
**One row per Parliament**

Summary statistics for Secretary of State churn across parliaments:

- `parliament_number`: Parliament identifier (55, 56, 57, etc.)
- `parliament_start_date`: When parliament began
- `parliament_end_date`: When parliament ended
- `parliament_duration_days`: Total days in session
- `num_secretaries_of_state`: Count of distinct SoS appointments
- `num_departments`: Count of distinct departments
- `median_tenure_days`: Median tenure length for SoS appointments
- `min_tenure_days`: Shortest appointment duration
- `max_tenure_days`: Longest appointment duration
- `appointments_per_year`: Normalized churn rate
- `media_era_flag`: Historical era (pre_radio, radio, tv, rolling_news, social_clip)

### `sos_churn_bar.png`

**Generated by**: `build_sos_churn_by_parliament.py`
**Type**: PNG visualization

Bar chart showing Secretary of State churn (distinct appointees per year) across parliaments with media era annotations (radio, TV, rolling news, social media).

## Updating Outputs

To regenerate all outputs in this folder, run:

```bash
python visuals/build_sos_churn_by_parliament.py
```

This script will:

1. Load the most recent cabinet ministers dataset from `../most recent extract/`
2. Fetch parliament periods (or load from cache if already fetched)
3. Analyze Secretary of State appointments
4. Generate outputs to this directory

## Using These Outputs in Other Scripts

### To use parliament periods cache:

```python
from pathlib import Path
import json
import pandas as pd

parls_cache = Path("data_sources/parliament/most recent output/parliaments_periods.json")
with open(parls_cache, "r") as f:
    parls_df = pd.DataFrame(json.load(f))
parls_df["parliament_start_date"] = pd.to_datetime(parls_df["parliament_start_date"])
parls_df["parliament_end_date"] = pd.to_datetime(parls_df["parliament_end_date"])
```

### To use churn summary:

```python
import pandas as pd

churn = pd.read_csv("data_sources/parliament/most recent output/parliamentary_churn_summary.csv")
```

### To reference cabinet ministers:

```python
import pandas as pd

ministers = pd.read_csv("data_sources/parliament/most recent extract/cabinet_ministers.csv")
```
